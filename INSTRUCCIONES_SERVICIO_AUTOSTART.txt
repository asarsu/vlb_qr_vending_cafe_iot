================================================================================
GUIA DE CONTROL Y MONITOREO DEL SERVICIO AUTO-START (KIOSCO QR VENDING)
================================================================================

El servicio está gestionado como un demonio systemd bajo el nombre:
  qr-vending.service

Dado que está configurado con política de autorrecuperación ("Restart=always"),
cerrar o matar la ventana de Python hará que el sistema la vuelva a levantar
automáticamente a los 5 segundos. Para controlarla desde la terminal debes
usar los comandos de systemctl.

--------------------------------------------------------------------------------
1. DETENER LA APLICACIÓN TEMPORALMENTE
--------------------------------------------------------------------------------
Detiene la aplicación y apaga la interfaz gráfica de inmediato.
(Permanece detenida hasta que la inicies manualmente o se reinicie la Raspberry Pi).
  
sudo systemctl stop qr-vending.service

--------------------------------------------------------------------------------
2. VOLVER A INICIAR LA APLICACIÓN
--------------------------------------------------------------------------------
Ejecuta las validaciones de red, túneles y levanta la pantalla gráfica:

  sudo systemctl start qr-vending.service


--------------------------------------------------------------------------------
3. REINICIAR LA APLICACIÓN (RESTART)
--------------------------------------------------------------------------------
Útil si actualizaste el código o la configuración y deseas reiniciar el ciclo completo:

  sudo systemctl restart qr-vending.service


--------------------------------------------------------------------------------
4. CONSULTAR EL ESTADO ACTUAL
--------------------------------------------------------------------------------
Muestra si está activa (active/running), detenida (inactive/dead) o con errores:

  sudo systemctl status qr-vending.service


--------------------------------------------------------------------------------
5. DESHABILITAR EL ARRANQUE AUTOMÁTICO AL ENCENDER LA RASPBERRY PI
--------------------------------------------------------------------------------
Si vas a realizar tareas de mantenimiento, desarrollo o calibración y NO quieres
que la app se abra sola al encender o reiniciar la Raspberry Pi:

  # Detenerla ahora y evitar que arranque al reiniciar:
  sudo systemctl stop qr-vending.service
  sudo systemctl disable qr-vending.service

  # Cuando termines y quieras volver a activar el auto-arranque permanente:
  sudo systemctl enable qr-vending.service
  sudo systemctl start qr-vending.service


--------------------------------------------------------------------------------
6. AUDITORÍA Y MONITOREO DE ERRORES CON JOURNALCTL
--------------------------------------------------------------------------------
Todos los eventos, validaciones y salidas de error quedan registrados en systemd:

  a) Ver logs en tiempo real (seguimiento en vivo mientras corre):
     journalctl -u qr-vending.service -f

  b) Ver únicamente los registros de errores y fallos:
     journalctl -u qr-vending.service -p err -e

  c) Ver todo el historial desde el último encendido/reinicio de la Raspberry:
     journalctl -u qr-vending.service -b

  d) Ver las últimas 100 líneas del log:
     journalctl -u qr-vending.service -n 100 --no-pager
